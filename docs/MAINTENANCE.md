# 仓库维护约定

- 日常入口只保留根目录的 open-app.cmd 和 update.cmd；新增辅助操作放 tools/，不得堆叠 start-xxx 演示入口。
- 公共逻辑放共享模块。旧入口被新入口替代后，同步移除重复实现并更新引用；不以“备用”为由长期保留不可用路径。
- 使用说明放 docs/，规划放 docs/planning/。过时操作由 Git 历史保留，不在当前目录复制 v1/v2/旧版文件。
- collector/、server/、tests/ 分别是客户端、可选服务端和验证代码，不属于可删除的杂物。
- 每次变更同步检查启动入口、文档链接、导入路径、测试和 Git 忽略规则。
- data、imports、training、虚拟环境、用户设置、日志和密钥不提交；仓库整理不删除用户本机数据。
- 删除 tracked 旧脚本会在 git pull 后同步删除；用户自己创建的未跟踪备份不会自动清除，避免误删个人文件。
